Dashboard chứng khoán Việt Nam kiểu TradingView, dữ liệu tổng hợp từ pipeline Python chạy local (7 chân kiềng: giá, metadata, vĩ mô, tin tức, cổ đông, chỉ báo kỹ thuật, báo cáo AI) cộng nhánh báo cáo tài chính quý (BCTC). Repo này là website tĩnh + tài liệu công khai — pipeline dữ liệu chạy trên máy local, không nằm trong repo.

Personal Vietnamese Stock Market Intelligence System. Stock Look Up là dự án cá nhân độc lập, không phải sản phẩm chính thức của vnstock và không liên kết, được tài trợ hoặc xác nhận bởi tác giả hay đội ngũ vnstock.

A personal, independent Vietnamese stock-market intelligence project. A local Python pipeline (not included in this repo) collects daily OHLCV prices, fundamentals, macro data, news, and quarterly financial statements for ~1,700 tickers, then mixes them into this static dashboard published via GitHub Pages.

Tính năng chính

  • Dashboard chính — báo cáo thị trường do AI tổng hợp, KPI, watchlist, kế hoạch hành động.
  • Bảng tín hiệu nến/SMC và bảng lọc đầy đủ (CANSLIM, SMC, thanh khoản...).
  • Quant engine offline — 10 chiến lược lọc + chấm điểm 0-100/mã.
  • Nhánh báo cáo tài chính quý (BCTC) cho ~650 mã.
  • Kho lưu trữ báo cáo/playbook tĩnh theo phiên — xem Archive.
Tech stack
HTML/CSS/JS thuần Tailwind CDN Bootstrap 5 DataTables Chart.js Lucide Icons

Không build step lúc publish — mở trực tiếp bằng file hoặc phục vụ qua GitHub Pages, thư viện load qua CDN. Riêng CSS Tailwind được build sẵn 1 lần offline (Tailwind CLI standalone), không chạy trong trình duyệt.
